# Contributing to Nexus Skills

Thank you for your interest in contributing to Nexus Skills!

Nexus Skills is an open-source library of reusable skills for Claude Code, Codex, and compatible AI coding agents. We welcome contributions from developers, AI engineers, researchers, technical writers, and anyone with useful engineering workflows to share.

You do not need to be a maintainer to contribute.

## Ways to contribute

You can contribute by:

- Creating a new skill for a practical engineering task.
- Improving an existing skill's instructions or examples.
- Testing skills with different coding agents.
- Fixing documentation, broken links, or technical inaccuracies.
- Improving validation scripts and automated checks.
- Reporting bugs, limitations, or security concerns.

## Before you start

- Browse the existing [`skills/`](skills/) directory to check whether a similar skill already exists.
- Read [`README.md`](README.md) and [`templates/SKILL.md`](templates/SKILL.md).
- Open an issue if you want to discuss a substantial new skill or architectural change before implementing it.
- Check that any third-party material you plan to include can be redistributed under the applicable licenses.

Small documentation fixes and straightforward improvements can go directly to a pull request.
